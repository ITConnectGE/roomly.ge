# roomly.ge — website

Public marketing site for **Roomly**, an AI-first PMS for hotels, aparthotels, apartments and guest houses.

- Live: https://roomly.ge (GitHub Pages, custom domain via `CNAME`)
- Static HTML/CSS, no build step. Edit `index.html` and `assets/styles.css`, push to `main`, Pages deploys automatically.
- Brand: Noto Sans Georgian · red `#B81D24` · ink `#1C1C1E` · ground `#F6F5F3` (matches the app design).

Application code lives in a separate private repository.
